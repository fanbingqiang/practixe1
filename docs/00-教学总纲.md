## 五、Debug 教学法：我要埋的 5 个 bug（对应阶段 5）

| # | 现象 | 根因 | 训练的能力 |
|---|------|------|-----------|
| 1 | 接口 500，日志 `NullPointerException` | 可选依赖注入没判空 | 读堆栈、异常断点、定位行号 |
| 2 | 查询返回字段全是 null | 实体属性名与表列名不匹配 | `application.yml` 开启 SQL 日志、看执行 SQL |
| 3 | 转账/扣库存失败但数据没回滚 | `@Transactional` 同类内部调用，代理失效 | 理解 AOP 代理、`AopContext` |
| 4 | 返回 JSON 死循环 / 少字段 | 双向关联 + Jackson 序列化策略 | 条件断点看对象图 |
| 5 | 创建时间差 8 小时 | JVM 时区 / `serverTimezone` 不一致 | 时区链路排查（JVM→驱动→MySQL） |

每个 bug 都要求你**先复现、再看日志、再断点、最后写回归测试**，我全程给提示不直接给答案（你也可以直接要答案，但那样学不到）。
